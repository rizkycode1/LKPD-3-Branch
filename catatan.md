## Catatan Pengerjaan

Saya membuat branch baru bernama fitur-profil
untuk mengembangkan halaman profil siswa.

Pada branch fitur-profil dibuat file profil.html
yang berisi halaman portfolio siswa.

Setelah selesai, perubahan pada fitur-profil
di-merge ke branch main.

Branch catatan-bukti digunakan untuk menyimpan
catatan dan bukti screenshot pengerjaan.

## Refleksi

### 1. Mengapa branch diperlukan?
Branch diperlukan untuk mengembangkan fitur tanpa
mengganggu proyek utama.

### 2. Apa keuntungan menggunakan branch?
Perubahan dapat dilakukan dan diuji terlebih dahulu
sebelum digabungkan ke branch utama.

### 3. Kapan sebaiknya membuat branch baru?
Branch baru dibuat ketika ingin membuat fitur baru,
memperbaiki bug, atau melakukan perubahan tertentu.
